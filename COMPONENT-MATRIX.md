# Komponentenmatrix

| Komponente | Zweck | Kosten | Status |
|---|---|---|---|
| .NET SDK | Windows Service/Build | kostenlos | erforderlich |
| .NET Runtime | Laufzeit | kostenlos | Self-contained Release bevorzugt |
| SQLite | lokale DB | kostenlos | eingebettet |
| Wireshark | Packet/Protocol Analysis | kostenlos/Open Source | optional |
| Npcap | Windows Live Capture | kostenlos fuer vorgesehene Nutzung, eigene Lizenz | ueber offiziellen Wireshark-Installer |
| Android Studio | Android Build | kostenlos | Entwicklung/Test |
| Android SDK | Android Build | kostenlos | Entwicklung/Test |
| OpenJDK 17 | Android Build | kostenlos | Entwicklung/Test |
| Git | Versionsverwaltung | kostenlos/Open Source | Build/Entwicklung |
| Inno Setup | Windows Installer | kostenlos | Build/Release |

Lizenzregel:
- Drittanbieter-Lizenzen beibehalten.
- Npcap nicht als eigene Kopie weiterverteilen.
- Offizielle Wireshark-Pakete verwenden.
- Versionen und Hashes vor jedem Release neu erfassen.
