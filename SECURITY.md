# Security Baseline

- Keine Passwoerter im Quellcode.
- Keine FRITZ!Box Credentials in Git.
- Keine privaten IP/MAC-Daten in Fixtures, sofern nicht synthetisch.
- Android Private Keys verbleiben im Keystore.
- Admin-Aktionen verwenden Challenge/Response.
- Evidence Events verwenden Hash-Chain.
- Vollstaendige PCAPs nur explizit im Incident Mode.
- Keine versteckte Inhaltsueberwachung.
