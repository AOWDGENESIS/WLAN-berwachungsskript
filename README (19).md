# GENESIS FRITZ!BOX GUARDIAN - Release Kit

Vorbereitetes Build-, Installations- und Release-Kit.

Ziele:
- Windows 11 Pro/x64
- lokal/offline-first
- FRITZ!Box TR-064
- SQLite
- Windows Service + UI/Tray
- optionale Paketaufnahme ueber Wireshark/Npcap
- Android Admin mit BiometricPrompt + Android Keystore
- Hash-Chain fuer Ereignisse
- automatisierte Tests, Preflight, Rollback und Regression
- kostenlose Komponenten bevorzugt, Open Source wenn technisch sinnvoll

Drittanbieter-Binaries werden nicht blind in das Projekt eingebettet.
Der Bootstrapper soll fehlende Komponenten erkennen, offizielle Quellen
verwenden, Hash/Signatur pruefen und danach den von dir gewaehlten
Installationspfad verwenden.

Dieses Paket ist das vorbereitete Fundament. Es ist noch kein behauptetes
Produktiv-Release.
